Research lab · since 2024

Computation that emerges from simple rules

We study models made of a state, a local rule and time: cellular automata, continuous media, small Turing machines. Training searches for the initial state that makes them compute.

Published

Emergent Models

A framework that turns dynamical systems into learning models, a latent-universality theorem, and experiments with 20–300 parameters.

EM43 computing x mod 4 for x = 70; trained on x ≤ 30.
In progress

Latent-universal machines

Small Turing machines with a fixed interface, where only the program changes between tasks. Testbeds for finding programs from examples.

LUTM-6 data tape (time →) running an evolved 32-symbol parity program; head in red.
In progress

Continuous and neural cellular automata

Real-valued media and neural local rules: one shared rule, a learned program per task.

CEM1D learned update rule (time →); inputs written at four ports every 30 steps.
Hypothesis

Reasoning models

Iteration, locality, and the ratio of parameters to computation time. Hypotheses with planned tests.

EM43 steps until halting vs input x, five tasks: computation time adapts per example.
Hypothesis

Parallel and analog substrates

What local, massively parallel hardware could compute, and the limits that locality imposes.

Rule 30 from one cell: influence spreads at most one cell per step (dashed).

Also: applied research, joint projects on problems that suit small iterated models, program search or evolutionary optimisation.

Result

140 bits, trained on 31 numbers, exact up to 1000

EM43 learns x mod 4 from the inputs 0–30. The same space-time mechanism works unchanged at any input size, which the paper calls geometric grokking.

x = 15 → 3 · inside training range

x = 47 → 3 · outside

Code and demos

Open code

Everything below is public. Demos run in the browser.

  • EM43

    1D, 4-state cellular automaton learning integer functions by evolutionary search.

    codedemo
  • GoL-EM

    Conway's Game of Life with the rule fixed; only glider placements are searched. Arithmetic (x + k) and CartPole.

    codearithmetic demoCartPole demo
  • CEM1D

    Continuous 1D lattice with three trainable coefficients controlling CartPole, with state retained between steps.

    codedemo
  • CEM2D · Meta-Life

    Two-channel continuous field (activation and memory) adapting online to food and poison phases.

    demo
  • LUTM-1

    Fixed one-tape Turing machine (150 states, 16 symbols) with a p#x interface; simulators in Python, NumPy and CUDA, an island GA and a program miner.

    code
  • LUTM-6

    Two-tape machine with 9 states and 144 transitions; read-only program tape; resumable GA.

    code
  • LUTM-6 and LU-A simulators

    Step-through browser simulators for LUTM-6 and the ten-operation LU-A language, with checked programs for the same tasks on both.

    codedemo
  • NCPU-EM-1D

    1D neural cellular automaton: one rule, a learned program per task, seven string tasks. Builds on NCPU by Zhechev and Walas.

    codedemo
  • NCPU-EM-2D and variants

    2D neural cellular automata with program tiles; single-task baselines; binary addition with single-cell inputs.

    ncpu-em-2dncpu-computerncpu-simplified
